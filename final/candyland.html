About the game.

Candyland is a multiplayer board game where players race to reach the Candy Castle first.

Along the way, players solve puzzles and use different candies to slow down their opponents. I built the project as an interactive C++ program while learning how game rules, player choices, and code structure all work together.

02

The goal.

I wanted to take a familiar game and figure out how to translate its rules into code.

The project focused on building clear turn-based logic, creating a game setup that could pull information from external text files, and making the experience easy enough for a new player to understand without knowing how the program works.

What I did

My contributions

  • Designed the game flow, including turn order, win conditions, and rules for special tiles.
  • Built the core C++ logic for player movement, card drawing, and score tracking.
  • Used external text files for game messages and board information so content could change without rewriting the program.
  • Tested the game, fixed logic issues, and adjusted prompts to make gameplay clearer.

What I learned

Skills gained

  • C++ functions, classes, loops, and control flow.
  • File input and output using external text resources.
  • Debugging larger systems with interconnected game logic.
  • Writing documentation and instructions for someone using a project for the first time.
